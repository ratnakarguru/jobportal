# JobPortal - Your Job Matching Platform

A modern, full-stack job portal platform that connects job seekers with employers. Built with **React + Vite** for the frontend and **FastAPI + PostgreSQL** for the backend.

🌐 **Live Demo:** [[https://jobportal-gules-ten.vercel.app](https://jobportal-gules-ten.vercel.app)](https://worklinejob.netlify.app/)

## ✨ Features

### For Job Seekers
- **User Registration & Authentication** - Secure account creation with password encryption
- **Profile Management** - Complete professional profile with skills, experience, and education
- **Resume Upload & Parsing** - Upload resumes and extract parsed data
- **Job Search & Discovery** - Browse and filter available job opportunities
- **Job Applications** - Apply to jobs with one click
- **Application Dashboard** - Track your applications and status

### For Employers
- **Job Posting** - Create and manage job listings
- **Candidate Management** - View and manage applications
- **Candidate Profiles** - Review detailed candidate information and resumes
- **Job Status Management** - Update job posting status (Open/Closed)

### General Features
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **RESTful API** - Clean and well-documented API endpoints
- **Database-Driven** - PostgreSQL for robust data persistence
- **CORS Enabled** - Cross-origin support for frontend deployment

## 🛠 Tech Stack

### Frontend
- **React 19.2** - Modern UI library with hooks
- **Vite 8.0** - Lightning-fast build tool
- **Bootstrap 5.3** - Responsive CSS framework
- **React Router DOM 7.16** - Client-side routing
- **Bootstrap Icons 1.13** - Icon library
- **React Icons 5.6** - Additional icon support

### Backend
- **FastAPI 0.139** - Modern Python web framework
- **SQLAlchemy 2.0** - ORM for database operations
- **PostgreSQL** - Robust relational database
- **Uvicorn 0.51** - ASGI server
- **Pydantic 2.13** - Data validation
- **PyPDF2 3.0** - PDF parsing for resumes
- **python-dotenv** - Environment variable management
- **pwdlib** - Secure password hashing with Argon2
